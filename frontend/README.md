# Cordys CRM 前端

Vue 3 + TypeScript + Vite + Element Plus 前端，位于后端仓库的 `frontend/` 目录，与后端代码一同版本管理。界面参照《Cordys-CRM-前端界面开发文档》与设计稿。现有后端接口通过 Vite `/api` 代理调用；尚无后端接口的统计图表和交互以明确标注的演示数据呈现。

## 本地启动

1. 安装 Node.js 20.19+ 或 22.12+。
2. 在本目录安装依赖：`pnpm install`。
3. 启动后端测试环境（当前默认端口 `http://127.0.0.1:8082`）。如后端地址不同，设置 `VITE_API_TARGET`。
4. 启动前端：`pnpm dev`，打开 `http://localhost:5173`。

也可以复制 `.env.example` 为 `.env.local`，修改后端目标地址。生产环境部署时设置 `VITE_API_BASE`，并配置对应反向代理。

## 页面

- 离线演示登录：用户名 `demo`，密码 `CordysDemo2026!`。登录前会探测 `/api/health`；仅后端不可达时创建本地演示会话，后端可用时拒绝该账号。演示样例与本地增删改保存在浏览器 `localStorage`，不会发送到后端；浏览器清理站点数据可重置演示数据。该凭据仅供本地 UI 演示，不可用于任何已连接后端的环境。

- 登录与注册申请：调用 `/api/auth/login`、`/api/auth/register`。验证码是前端演示值，尚无后端验证码服务；忘记密码暂未接入。“记住我”只记住用户名，**登录令牌仅写入 `sessionStorage`**，不落 `localStorage`，关闭浏览器后需重新登录。
- 工作台：跟进记录从 `/api/follow-records` 读取，`targetType`／`targetId` 由客户与商机列表还原为名称，并显示跟进人与格式化时间；统计卡片、漏斗、趋势图为演示数据，等待后端聚合接口。
- 线索、客户、商机、合同：
  - 字段级筛选：客户（客户名称、所属行业、客户状态）、线索（线索名称、线索来源、线索状态）、合同（合同名称、合同状态）。筛选在前端对已加载数据执行。
  - 名称解析：列表、详情与看板把 `customerId` 显示为客户名称；`ownerId` 只能解析当前登录用户，其余显示为“用户#ID”（见下文权限限制）。
  - 导出：按当前筛选结果导出 CSV，带 UTF-8 BOM，可直接用 Excel 打开。
  - 表单字段长度上限与后端数据库列宽对齐（如电话 32、地址 500、合同编号 64）。
  - 列表与看板空态均提供新增入口。
- 商机看板：使用现有商机更新接口保存阶段；后端尚无单独的状态迁移与可执行迁移查询接口。
- 系统管理：默认进入“系统总览”，提供用户管理、角色权限、数据字典三张入口卡片与操作日志表。操作人由 `operatorId` 解析为姓名（该页仅管理员可见）；日志仍在一次性加载后于前端过滤。
- 注册审核：保留在左侧导航，用于审核注册申请。

## 已知限制与待补后端接口

| 能力 | 现状 | 需要后端提供 |
| --- | --- | --- |
| 负责人姓名 | 仅能解析当前登录用户 | 业务返回体补充 `ownerName`，或提供非管理员可读的 `GET /api/users/options` |
| 工作台统计 | 演示数据 | 统计与漏斗聚合接口 |
| 列表分页与筛选 | 一次性加载后前端处理 | 分页与筛选查询参数 |
| 下拉选项 | 使用前端写死的枚举值 | 按类型读取字典的接口，替代现有全量 `GET /api/dicts` |
| 操作日志 | 只读，前端过滤 | 分页、按模块／时间筛选接口 |
| 验证码、忘记密码 | 前端演示 | 验证码服务与找回密码流程 |

`/api/users` 目前仅管理员可读（`AdminAccessInterceptor` 限制），因此普通账号无法解析他人姓名——这是权限设计的结果，前端已按降级显示处理。

下拉字典、分页、统计、状态迁移和验证码切换到真实接口后，应删除对应演示数据/临时标记。
